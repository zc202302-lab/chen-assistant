# 晨的助手 v0.2.3

个人长期使用的 PWA 工作助手。当前客户管理以**连续、高频、低遗漏的缴费作业**为第一核心场景。

## 客户工作区

客户详情保持在一张工作页中：

- 顶部是压缩后的客户资料与待办概览。
- 下方横排 `缴费 / 业务 / 联系人 / 待办 / 跟进`，点击后只切换下方内容，不跳转页面。
- 桌面端客户顶部与横排功能区固定显示，长缴费清单滚动时仍可随时切换模块。

## 缴费工作区

一个客户每月一次性处理所有应缴业务。高密度单行主要展示：

`拖动 | 两个默认属性 | 号码 | 账号 | 金额 + 核对状态 | 固/变`

核心操作：

- 单击号码或账号：复制。
- 双击号码或账号：快速修改号码/账号等基础字段。
- 点击第一列“属性”：弹出完整属性框，可编辑当前业务全部主要属性，并选择第一列默认显示的两个属性。
- 单击金额：自动全选。
- 金额不变：直接 Enter 确认。
- 金额变化：输入新金额后 Enter。
- 本月不缴：输入 `0` 后 Enter，TXT 自动排除。
- Enter 保存后自动跳到下一条未核对变动业务，并把下一条金额直接全选进入编辑状态。
- 此时即使点击号码/账号复制，金额编辑焦点与全选状态也会保留，便于切换到 BOSS 查询后继续录入。
- 每行 `○ / ✓` 显示本月是否核对，同时顶部显示“需核对 / 未核对”数量，形成双重防漏。
- 固定金额业务自动确认；`固 / 变` 切换按钮保留但低视觉权重。
- 拖动每行左侧手柄可调整顺序，并持久化保存。

## 金额与历史

- 新月份不清空金额，而是继承上一期金额。
- 变动业务继承金额但本月重新处于未核对状态。
- 固定业务按当前有效固定规则自动确认。
- `payment_entries` 按“业务 + 月份”保存实际金额和本月核对状态。
- `service_payment_rules` 保存固定/变动规则的生效月份，切换规则不会改坏历史记录。
- 0 元表示“本月已核对但无需缴费”。

## 业务顺序与属性

`services.sort_order` 保存手工拖动顺序。

每项业务还保存：

- `display_attr_1`
- `display_attr_2`

默认是“类型 + 姓名/属性”，也可改成发票组、缴费周期、付款方式、发票类型、套餐类型、上次缴费、备注等组合。以后新增属性时可以继续扩展这个属性选择机制，而不必重做缴费表格。

## 缴费 TXT

只有本月所有需要人工核对的变动业务都核对完成后，才允许生成正式 TXT。

当前格式严格为：

```text
号码|金额
```

0 元项目自动排除，不添加标题、合计或说明。

## 部署

服务器目录：

```text
/opt/chen-assistant
```

正式版本日常更新：

```bash
cd /opt/chen-assistant
./deploy.sh
```

部署脚本会自动备份 SQLite 数据库、拉取 GitHub `main`、安装依赖、执行数据库迁移、重启服务并检查 `/health`。

## 安全边界

`.env`、`data/app.db`、`.venv/` 不上传 GitHub。个人网址密码目前仍是服务器端 Fernet 加密，不是零知识密码保险箱。
