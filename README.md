# 晨的助手 v0.2

个人长期使用的 PWA 工作助手。当前阶段客户管理以**缴费作业**为第一核心场景，同时保留客户资料、联系人、业务、开票分组、待办、跟进和个人网址账户等能力。

## v0.2 的缴费工作方式

每个客户一次性处理本月所有需要缴费的业务：

1. 打开客户详情，首先进入“缴费工作区”。
2. 每项业务同时展示号码和账号；点击任意一个大区域即可复制。
3. 金额字段不会在月初清空：系统自动沿用上一期金额。
4. 变动金额业务虽然显示上一期金额，但状态为“待核对”；查询 BOSS 后：
   - 金额不变：点金额，直接按 Enter；
   - 金额变化：点金额后直接输入新金额，按 Enter；
   - 本月不缴：输入 `0`，按 Enter。
5. Enter 保存后自动定位下一项待核对业务。
6. 固定金额业务自动沿用并确认；如果直接修改固定金额，则从本月起更新固定规则。
7. 所有待核对项目完成后才生成正式缴费 TXT。
8. TXT 只包含非 0 元项目，每行严格为 `号码|金额`，没有标题、汇总或说明。

## 数据模型关键点

- `payment_entries`：按“业务 + 月份”保存金额，并单独保存 `confirmed`（本月是否核对）。
- `service_payment_rules`：保存固定/变动规则的生效月份，因此以后固定→变动、变动→固定不会改坏历史月份。
- `services.active_from_period / inactive_from_period`：新增/停用业务按月份生效，历史记录不物理删除。
- `.env`、`data/app.db`、`.venv/` 均不上传 GitHub。

## 部署

服务器目录：

```text
/opt/chen-assistant
```

日常更新使用：

```bash
cd /opt/chen-assistant
./deploy.sh
```

部署脚本会自动备份 SQLite 数据库、拉取 GitHub `main`、安装依赖、执行数据库迁移、重启服务并检查 `/health`。

## 安全边界

个人网址密码目前仍是服务器端 Fernet 加密，不是零知识密码保险箱。数据库和 `.env` 需要分别安全备份。
