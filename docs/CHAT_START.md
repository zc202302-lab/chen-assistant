# 晨的小助手 · 新聊天接管入口

这个文件用于在 ChatGPT 聊天达到长度上限后快速继续项目。

新聊天直接发送下面这段：

> 继续开发我的“晨的小助手”。仓库：https://github.com/zc202302-lab/chen-assistant。先读取当前 main 和 docs/AI_HANDOFF.md，以仓库实际代码为准。不要根据旧聊天猜测状态。确认当前版本、main、生产基准、已完成事项、未完成事项后继续上次开发。

接管规则：

- 仓库当前 `main` 是事实来源。
- `docs/AI_HANDOFF.md` 记录生产基准、产品决策、治理状态、未完成事项和下一步。
- 重要决定、合并、部署、未完成任务变化后，要同步更新 `docs/AI_HANDOFF.md` 顶部“当前接力状态”。
- 不需要复制旧聊天，也不需要用户重新描述整个项目。

当前状态请始终以 `docs/AI_HANDOFF.md` 顶部为准，不在本文件重复维护版本号，避免双份状态过期。
