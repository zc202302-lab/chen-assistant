# 小助手收集：原网页等价的小程序

AppID wxcb9395eac340e8cb，导入当前交付版本的 miniprogram/ 即可。后台须先部署本PR后端Web1.7.33。

## 使用流程

直接打开 → 填写号码 → ＋增加行 → 提交号码 → 未加号码列表。首页“查看未加号码”可直接查看；列表提供继续填写与刷新，以及新增/之前、号码、北京时间提交时间，空表显示目前没有未加号码。

无须设置入口码、启动参数或勾选额外说明。小程序调用GET /number-submit/mini/entry自动解析当前单一公共收集入口，再以Bearer调用原提交或新增pending接口。分享有参数时仍自动解析，明确失效的邀请不回退到默认入口。不要把真实邀请、AppSecret或后台凭据写入代码。

## 与原网页的对应

填写标题、号码标签、输入框、灰色虚线＋、黑色提交按钮、查看未加号码及提交后文案/跳转对应number_submit_v162.html、number_pending_v162.html及number-inbox-v162.css。不额外增加业务UI；微信自身的原生导航、胶囊和键盘属于平台容器，不能视为业务页面像素一致的证明。

当前手工填写普通input，无微信手机号、通讯录或其他受保护隐私API调用；不主动模拟隐私API来强制弹窗。用户点击提交为主动上传号码的操作。仍须在微信后台如实声明实际处理的信息、运营主体及联系方式，不以代码替代平台审核。

## 验证

本地真实HTTP覆盖共用收件箱、批量原子/去重、邀请轮换、入口自动解析、Bearer列表鉴权、仅公开字段、批次标记、已完成排除和不缓存。Node覆盖无参干净表单/自动连接、分享、失效隔离、防重复、失败保留、提交后跳列表、刷新/继续填写。仍需完整CI与微信实机验证。

默认小程序面向所有打开者连接同一个公开收集入口；列表可见范围与原公共网页相同，不能扩展为管理员/桌面接口，也不返回备注、后台凭据及已完成记录。
