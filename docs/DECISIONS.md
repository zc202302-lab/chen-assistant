# 晨的小助手 · 重要决策记录

本文件记录长期有效、以后可能需要追溯原因的决定。动态进度仍写入 AI_HANDOFF。

## Windows 助手统一发布

**决定：** 短信、Foxmail、久坐统一整合进 `win-assistants`，只保留一个用户侧“检查更新”。

**原因：** 避免多个 Windows 工具各自维护更新器、Git 依赖、托盘和版本，降低用户更新与故障排查复杂度。

**结果：** 久坐模块作为内置模块随整个 win-assistants EXE 发布；独立久坐 Git 更新入口不再作为正式用户路径。

## 久坐成熟能力迁入而非重写

**决定：** 迁移已经验证过的久坐核心能力，不重新从零设计识别与状态机。

**原因：** 现有多区域人体存在检测、RTSP、强制休息、DPAPI 和统计能力已经过多轮实际调试，重写会增加回归风险。

## GitHub 作为项目长期记忆

**决定：** 项目跨聊天窗口所需的信息长期保存到仓库文档、PR、commit 和 Actions，不再依赖超长聊天提示词。

**文档分工：**

- AI_HANDOFF：动态状态
- PROJECT_CONTEXT：接管入口
- PRODUCT_REQUIREMENTS：稳定产品规则
- ARCHITECTURE：高层架构
- DEVELOPMENT_RULES：开发/CI/部署约束
- DECISIONS：重要决策历史

**原因：** 聊天上下文会截断、过期或混入旧状态；GitHub 可版本化、可审计，并能让新聊天直接恢复实际开发状态。
