# 生活模块手动新建菜谱

生活首页和菜谱库右上角均提供“＋ 新建菜谱”。

1. 填写菜名、分类、标签、标准主材重量和单位，可补充说明。
2. 点击“创建并编辑配方”，进入已有配方编辑页，添加配料与步骤，填写本次说明并保存。
3. 新菜谱会出现在生活最近菜谱、数量、菜谱库、分类和搜索中，标记为“手动创建”。支持后续编辑、配方换算、历史版本和原有A4打印。

沿用现有两步创建模式：创建时先保存基本信息和初始V1，填写配方后保存V2，以后继续保留各版本。若暂时中断填写，可以从菜谱库重新进入编辑标准。新建页点击取消不会创建记录。同名菜谱拒绝重复创建，不会覆盖原菜谱。

只扩展可见性，不改原导入内容：手动来源与已有18个标准模板并列显示，历史仅目录类条目仍保持原展示策略；不会把手动菜谱伪装成Excel导入。已有归档规则保持，所有数据仍在原SQLite数据库和备份中。
## 按环节编辑标准

“编辑标准配方”按腌肉、碗汁等环节集中展示物料，同组只填写一次环节名称。常用字段为物料、用量、单位；展开“比例与备注”可保留按主材比例、固定量、手工决定和备注。“所属环节”可将单个物料移到其他组，用量、单位、比例和备注原样保留。支持增删环节、环节上下移动、组内添加/删除物料，删除含物料环节前确认。环节名称不可重复，避免保存后混组。

已有配方按原分组首次出现的顺序归组，各组物料顺序不变；原字段、步骤及隐藏的历史步骤属性继续保留。不引入步骤外键，环节名称沿用原有分组字段；保存生成新版本，历史版本不覆盖。空环节只有加入物料后才会保存。改进说明常显，菜谱信息按需展开。手机主输入同一行，底部保存栏压缩并保留返回放弃路径。
