# Foxmail v0.7 本地启动桥接方案

## 目标

解决旧 Simple MAPI 路径可能返回成功但 Foxmail 实际未打开写信窗口的问题。

## v0.7 主链路

1. 浏览器调用本机 `127.0.0.1` Foxmail helper。
2. helper 校验请求来源与必需字段。
3. helper 定位 `Foxmail.exe`，使用 `mailto:` 启动写信窗口。
4. helper 必须检测到新的 Foxmail 写信窗口并将其置前。
5. 客户专属 TXT 在本机生成临时文件，使用文件剪贴板方式粘贴到写信窗口。
6. 只有启动窗口和附件准备均验证成功，helper 才返回 `verified=true`。
7. 浏览器只有收到 v0.7 的已验证响应后，才允许“发起缴费”工作流进入下一阶段。
8. 不自动点击“发送”，最终发送仍由用户人工确认。

## 兼容边界

- 服务器端客户独立缴费模板与 TXT 内容生成逻辑不变。
- 历史缴费回退、客户状态、资料、导入等能力不得因本功能被弱化。
- Simple MAPI 不再作为 v0.7 主路径。
- 本地 helper 继续只监听回环地址，并限制允许的站点来源。
- Windows PowerShell 5.1 必须通过语法与 ASCII 安全检查。

## 合并门槛

PR #23 仅在新 Foxmail 专项合同、Windows helper 检查以及全部历史 CI 验收同时通过后合并。历史测试不得为迁就新方案而删除、跳过或放宽。
