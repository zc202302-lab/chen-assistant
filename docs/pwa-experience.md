# v1.7.2 主屏幕体验

增强仅在 standalone（包括 iPhone navigator.standalone）且已登录的主屏幕应用中启用。常规网页版继续使用原有交互和导航，四个主区域和主站域名不变。

- 复用现有前进/后退导航；返回和刷新时恢复滚动位置及页面本地筛选。查询参数仍由原有路由保存，不拦截导航、不引入 SPA 路由。
- 客户新建、资料编辑、清单记录采用显式恢复草稿。草稿使用 sessionStorage，按登录会话和完整页面路径隔离，保留两小时；不保证系统回收应用后仍保留。隐藏字段、密码、文件、CSRF 和版本控制字段均不写入。保存失败时保留草稿，成功跳到对应详情页后清除。清单字段名称或类型变化时不恢复不匹配字段，后台仍校验当前版本。
- 手机主屏幕版增加底部当前页高亮、安全区域和输入字号适配；键盘弹出时收起底栏；号码输入使用电话键盘。
- 新 Service Worker 等待用户点击“更新”后激活。后台下载静态界面资源，绝不缓存私有页面或数据库。页面有编辑操作时提示先保存并离开编辑页，不自动刷新。

部署仍使用现有 main 自动更新机制。CI 新增真实 Chromium 场景：正常网页不启用增强、草稿恢复、排除私密字段、验证失败保留草稿、保存成功清除、筛选和滚动恢复、未保存更新保护、损坏存储容错。线上检查核对新增两个静态资源的精确内容。
