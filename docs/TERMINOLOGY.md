# 网站、手机和电脑客户端：固定术语

这是用户于2026-11-02明确规定的称呼。后续需求、界面、说明和开发交接均按此解释，不因打开页面所用的硬件不同而改变含义。

| 用户说法 | 唯一含义 | 提醒职责 |
| --- | --- | --- |
| 网站、网页、网站中、网页上 | 在普通浏览器中打开的晨的助手网站，包括电脑浏览器和手机浏览器 | 管理提醒设置；不作为通知接收端 |
| 手机、手机上、手机端 | 点击添加到手机桌面的晨的助手图标打开的应用（PWA） | 接收手机通知；配置手机提醒规则 |
| 电脑、电脑上、电脑端、电脑客户端、Windows 助手 | Windows 助手客户端程序 | 接收电脑通知；在客户端配置电脑提醒规则 |

## 表达规则

- 不使用“本机”“当前设备”“此设备”“该端”等不能直接看出平台的指代。明确写“网站”“手机”或“电脑客户端”；需要区分多部手机时可写“这部手机”。
- 用户说“网站中修改”，是在网站界面修改；说“电脑客户端中修改”，是在Windows助手中修改；说“手机上修改”，是在手机桌面图标打开的应用中修改。
- 手机和网站可能复用Web代码，但产品概念、通知入口及需求解释必须区分。电脑浏览器不是电脑客户端；手机Safari普通标签页不是用户简称的手机端。
- 提醒只发送到手机和电脑客户端。不再把普通浏览器通知当第三个接收端，也不要求用户理解推送订阅等内部实现概念。

## 提醒控制范围

- 通知总开关：暂停或恢复手机和电脑客户端两端提醒。
- 手机提醒开关：只控制手机；方式、内容、时间、循环在网站或手机中配置。手机首次连接通知必须在手机中由用户点击授权，网站不能代替手机取得系统权限。
- 电脑提醒开关：网站或手机中仅控制电脑提醒启停；与总开关共同形成电脑客户端接收闸门。方式、内容、时间、循环仍由电脑客户端保存和执行，不能被手机规则覆盖。
- 关闭任何接收开关都保留已存规则；总开关再次打开不能越过已关闭的手机或电脑独立开关。
