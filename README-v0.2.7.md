# 晨的助手 v0.2.7

本版聚焦缴费列宽、优惠续约工作流与业务编辑效率。

- 缴费工作区的属性、号码、账号、金额四列支持拖动调整宽度；宽度按客户分别保存。
- 优惠工作区只显示“已经到期”和“即将到期”，不显示后续到期。
- 优惠按号码聚合：号码在上方突出显示，同一号码下可有多个优惠。
- 号码和优惠名称均可直接复制；完成公司系统续约后，只需修改新的到期时间并保存。
- 同一号码下的多个优惠支持拖动调整顺序，顺序按客户和号码持久化。
- 添加优惠改为手工输入号码，系统自动匹配该客户业务并归入对应号码。
- 首页优惠提醒按客户汇总，每个客户只显示一行，并在右侧显示需要处理的优惠数量。
- 业务编辑提交后恢复原滚动位置，避免每次保存后跳回顶部。
- 业务优惠筛选只保留：已经到期、即将到期、无优惠；未来优惠仍作为业务信息存在，但不进入行动提醒。
