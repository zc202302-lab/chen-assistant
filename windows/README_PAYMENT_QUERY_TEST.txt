晨的小助手 · 缴费金额自动查询测试版
====================================

安全边界
--------
本程序只会：
1. 在已经打开的业务查询页面填写账号并点击“确定/查询”；
2. 读取产品类型及账单金额；
3. 计算结果并写入 Y:\ChenBridge\results。

本程序不会点击或提交任何实际缴费按钮。

首次诊断
--------
1. 使用已经添加 --remote-debugging-port=9222 的快捷方式打开 Qaxbrowser。
2. 打开业务支撑系统和余额查询窗口。
3. 浏览器访问 http://127.0.0.1:9222/json/list，确认存在 10.19.89.56 页面。
4. 双击“payment_query_diagnostic.cmd”。
5. 输入一个可查询账号，等待窗口显示产品类型、原始金额和最终金额。

共享目录监听
------------
首次诊断成功后，双击“payment_query_agent_start.cmd”。
程序将监听云电脑的 Y:\ChenBridge，对应本地电脑的 F:\ChenBridge。

遇到错误时请保留诊断窗口截图，不要反复点击业务系统。
