# 云电脑助手：集团成员批量添加

## 输入文件

助手监听 `Y:\ChenBridge\号码加集团.xlsx`。工作簿第一张工作表不设表头：A 列是服务号码，B 列是集团搜索值。每一行代表一个成员任务。号码和集团编号按文本读取。

号码收集页面的“批量加集团”按钮会从所有未加号码生成此文件，集团编号暂定为 `c7210826122`。本机浏览器首次点击时需授权选择与云电脑 `Y:\ChenBridge` 同步的共享文件夹。

## 执行流程

1. 使用带 `--remote-debugging-port=9222` 参数的 Qaxbrowser 快捷方式启动浏览器，并保持已登录的集团客户系统页面打开。
2. 运行 `start_agent.cmd`。助手会逐行搜索集团编号，进入“成员信息”，检查成员列表是否已存在该号码，再点“新增”。
3. 输入服务号码并等待姓名回填，选择“人工识别真实性：集团通讯录”，然后点击“确定”。
4. 结果写入 `Y:\ChenBridge\results\号码加集团_结果_*.json`。原任务工作簿移入 `processed`。格式错误的工作簿移入 `errors`。

如果集团不唯一、页面字段无法唯一匹配、姓名未加载或提交结果不确定，助手会暂停本批剩余任务并写明原因。提交结果不确定时不会自动重试，需先人工查看成员列表。重复成员会跳过。

## 初次验证

先将安装包解压到云电脑的固定目录（例如 `C:\Tools\CloudMemberAddAgent`），不要在 ZIP 内直接运行。共享任务目录仍是 `Y:\ChenBridge`，程序目录与共享目录可以分开。

启动前可在程序目录运行 `CloudMemberAddAgent.exe --check-browser`。此命令只检查调试连接和业务搜索框，不提交成员。若提示未准备好，请使用调试快捷方式启动浏览器，重新登录集团系统并打开顶部搜索框所在页面。通过检查后双击 `start_agent.cmd`。

助手启动时及领取每批 Excel 前会再次检查浏览器。连接失败或找不到搜索框时退出并显示原因，原 Excel 留在共享目录，修复连接后可以再次启动。找到搜索框不代表所有后续页面已验收；仍需先用一个号码验证真实流程。

先运行 `CloudMemberAddAgent.exe --check-file "Y:\ChenBridge\号码加集团.xlsx"` 检查 Excel 格式。准备好业务页面后，再启动 `start_agent.cmd`。该助手只提交集团成员新增表单，不进行缴费操作。
