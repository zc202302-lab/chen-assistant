# 云电脑工作区切换器

这个方案不再尝试把云电脑画面重新编码进浏览器，也不使用共享文件夹或剪贴板做实时链路。

它直接复用“移动云电脑”客户端本身已经存在的低延迟远程通道，只解决最影响效率的问题：在本机与云电脑之间快速切换、固定布局和恢复焦点。

## 识别目标

优先识别：

- 进程：`uSmartView_VDI_Client.exe`
- 兼容窗口标题：`我的电脑`

## 快捷键

- `Ctrl + Alt + Space`：切到云电脑；再按一次返回切换前的本机窗口。
- `Ctrl + Alt + Enter`：云电脑最大化。
- `Ctrl + Alt + Right`：云电脑停靠屏幕右侧约 62%。
- `Ctrl + Alt + Left`：云电脑停靠屏幕左侧约 62%。
- `Ctrl + Alt + Esc`：最小化云电脑并返回本机。

## 启动

双击：

```
start_cloud_workspace.bat
```

或：

```bat
python cloud_workspace_switcher.py
```

这套方案完全运行在本机，不要求云电脑访问公网，也不会改动移动云电脑的网络协议。
