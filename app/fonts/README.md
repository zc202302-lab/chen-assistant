# Recipe PDF font

ChenRecipeSans.ttf.z is a zlib-compressed, regular-weight, BMP subset of Noto Sans SC from https://github.com/google/fonts/tree/main/ofl/notosanssc, downloaded 2026-10-24. It is renamed for this derived subset. It is decompressed in memory and ReportLab embeds only used glyphs into each PDF. No font is downloaded at runtime. See OFL-NotoSansSC.txt for copyright and license.
